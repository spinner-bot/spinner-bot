# 时间线与 Current Focus 连续画布

日期：2026-10-11。此版将时间线末端、三点省略号和 Current Focus 列表放在同一张自带深色背景的 SVG 中，避免两个组件之间露出网页背景。桌面和手机分别由 `scripts/build_timeline.py` 生成，README 使用版本化图片地址，避免旧图缓存。

- 所有时间节点窗口等宽且纵向对齐。桌面窗口横向范围为 `112–1088`，轨道中心位于 `56` 与 `1144`；手机窗口范围为 `54–336`，轨道中心位于 `27` 与 `363`。外框与轨道、轨道与窗口之间留出明确空隙。
- 年度横线两端采用更大的圆角弯折：桌面转弯尺度 `120`，手机 `70`，分别约为上一版的 3.5 倍和 3.2 倍。
- 末端从右侧轨道以平滑曲线进入斜线，直线段的屏幕坐标斜率约为 `1/√3`，再平滑转入画面正中的短竖线。竖线末端是沿下方延伸的三个点，下面直接进入 Current Focus。
- 时间节点日期仅显示英文季节与年份；节点正文以及 Current Focus 的每条内容都在所有屏宽下按英文、中文上下排列。
- 四条关注方向保留在生成脚本的 `FOCUS` 数据中，列表使用与时间线相同的字体、薄边框、青色强调线和暗色底。
- 首版、第二版的设计文档与预览图片仍保留。本版预览为 `previews/timeline-desktop-v3.png`、`previews/timeline-mobile-v3.png`。
