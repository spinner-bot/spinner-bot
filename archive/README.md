# 归档说明

此目录保存目前不参与个人主页展示或日常资源生成的旧版内容，便于以后查阅、复用。文件只做归档移动，没有删除原始资料。

- 根目录：早期 README（`legacy-profile-readme.md`）与赛博霓虹版 SVG、暂时隐藏的 Languages and Tools 片段。
- `legacy-assets/`：旧打字 GIF 和 About Me 初版辅助 SVG。
- `legacy-scripts/`：旧打字 GIF 生成脚本。
- `design-history/`：时间线 v1–v5 的设计记录、预览图，以及 About Me 初版预览。历史记录保留当时措辞，个别路径描述反映旧目录结构。
- `notes/`：早期研究、需求与状态快照，可能包含已经过时的规划，不代表当前 README 的要求或状态。

当前 README 使用的 SVG 仍在 `assets/`；现行构建与预览脚本仍在 `scripts/`；最新设计记录和预览仍在 `docs/design/`。
