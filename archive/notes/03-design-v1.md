# Profile README v1 设计文档

## 主题
**Cyberpunk Neon Terminal / 赛博朋克霓虹终端**

## 配色方案
| 颜色 | 色值 | 用途 |
|------|------|------|
| Neon Green | #00ff88 / #39ff14 | 主色调 |
| Neon Magenta | #ff00ff | 高亮/标题 |
| Neon Cyan | #00ccff | 链接/次要 |
| Neon Orange | #ff6600 | 强调 |
| Dark BG | #0D1117 | 背景 |

## 板块结构
1. 霓虹头部横幅 (neon-header.svg)
2. 状态条 (status-bar.svg)
3. 打字动画（EN↔CN 交替循环）
4. 角色面板 (RPG Character Sheet)
5. 研究方向 (Multimodal OPD)
6. 技术武库 (Arsenal)
7. 精选项目
8. GitHub 统计面板
9. 贡献街机 (蛇形动画 + 3D贡献墙)
10. 联系方式 + 页脚

## 语言策略
- 板块标题：EN / CN 并列
- 正文：EN 在前，CN 在后
- 打字动画：EN→CN→EN→CN 交替循环

## 炫技元素
- SVG 霓虹发光动画 (CSS @keyframes)

- github-readme-stats 统计卡片
- contribution snake 动画
- 3D contribution wall
- shields.io 徽章云
