# About Me 区块设计记录

日期：2026-10-11。此版将 About Me 放在动画封面与贡献蛇形图之后，以左右双栏并列展示英文和中文。

## 内容与顺序

- 标题：`ABOUT ME · 关于我`，英语在前。
- 左栏为用户提供的英文原文，右栏为中文原文；两栏保持相同的语义顺序，不改写正文。
- 栏目眉题分别标为 `01 / PROFILE · ENGLISH` 与 `01 / 个人简介 · 中文`。

## 视觉实现

- README 用语义化 HTML 表格做两列，正文是普通段落文本，便于选择、检索和屏幕阅读器读取。
- 两列标题下用 `assets/about-rule.svg` 作一条低对比细线和小节点，列间用 `assets/about-divider.svg` 轻分隔，呼应封面计算轨道的线性语言。
- 封面与贡献图保持居中；About Me 离开居中容器后采用左对齐，减少长段落的阅读负担。
- 装饰不使用动效，不与正文竞争注意力。
- `scripts/preview_about_me.py` 生成桌面与窄屏预览，截图保存在 `previews/`。

## 已知取舍

GitHub Profile README 不支持可靠的自定义响应式 CSS。桌面两列清晰；窄屏预览中英文列变窄、段落变长，影响阅读。后续可在保持桌面双栏的同时，评估 GitHub 对最小列宽和横向滚动的呈现，或改为窄屏优先的双语上下排列（英文在前、中文在后）。
