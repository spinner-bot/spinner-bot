## 设计来源与方向

参考本地 `F:\资源夹\赛事\HydroAI Flow\assets\hero.svg` 与其设计文档：独立 SVG、自带深色背景、非对称左文右图、分层动画、减少动画模式。这里沿用方法，不沿用水波和代理模型核球。

本卡主题为 **computational identity / 计算中的数字身份**。右侧使用精密坐标环、连接网络、分层线条和信号点表示 AI 的持续推理。避免具象机器人或大脑图标。动画强度低，文字始终是第一视觉焦点。

## 构图与规格

- 画布 1200 × 440，作为 README 全宽图片引用；背景 `#071219`，内圆角 20。
- 左侧文字起点 x=76；右侧视觉中心约 (942, 215)，主图直径约 330。
- 顶部标签在 y≈72；姓名在 y≈205；概括句在 y≈307；底部关键词在 y≈390。
- 底部关键词使用细分隔线和小型三节点序列，与右侧计算图形在形式上呼应。
- 字体采用系统回退栈，重点在文字的尺寸、字重与留白，而非外部网络字体。
- 色彩：深青黑背景，白青色主字，灰蓝次级字，薄荷青主强调，少量蓝紫光晕。

## 动画设计

- 文案以 12 秒为一个周期：英文停留约 5 秒，中文停留约 5 秒，两次柔和淡化切换。姓名与其他可变文案同步。
- 正反旋转的细环分别用 30 秒和 22 秒线性循环；连接网络 7 秒轻微呼吸；信号沿轨道移动。
- 动画以透明度、旋转和路径运动为主；静态帧必须完整可读。
- `prefers-reduced-motion: reduce` 关闭所有运动；此时英文作为默认静态语言，中文信息仍在 README 的 `alt` 中提供。

## 技术取舍

- GitHub README 引用独立 `assets/hero.svg`；不内联 SVG，不使用 JavaScript、外部字体或外部资源。
- SVG 包含 `<title>`、`<desc>`；README 的 `<img alt>` 同时写明中英文身份及概括句，因为图像上下文的辅助技术通常优先读取 `alt`。
- 深色背景内置，亮色与暗色 GitHub 主题下外观一致。
- 旧打字 GIF 保留在 `assets/`，其生成脚本保留在 `scripts/`，作为本次设计演变的原始资料。原有蛇形图和工具图标仍接在封面下方。
